# MailSlurp for Cursor

Connect MailSlurp to check workspace access and test how email looks in real clients. This plugin includes the MailSlurp MCP server and skills for connection diagnostics and email rendering.

In Cursor, open Customize, select the MailSlurp MCP server and choose Authenticate. Sign in to MailSlurp and approve the permissions needed for your task. An existing MailSlurp account is required. Keep API keys and passwords out of chat.

Try “Check my MailSlurp connection and tell me whether I can read device rendering results.” Then try “Show the screenshots for my most recent completed email render.” To start a new render, review the selected clients and credit estimate before confirming.

The permissions you grant and your MailSlurp plan determine which tools are available. For local development, follow Cursor’s [local plugin testing instructions](https://cursor.com/docs/plugins#test-plugins-locally).
